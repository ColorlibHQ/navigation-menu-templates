Webhooks

Webhooks tell your server when a shipment changes state, so you don’t have to poll the API. Each event is a signed POST request with a JSON body.

Register an endpoint

Create an endpoint in the dashboard or with the API. You can subscribe to all events or pick the ones you need.

curl https://api.parcelworks.example/v3/webhooks \
  -H "Authorization: Bearer $PW_SECRET_KEY" \
  -d url="https://shop.example/hooks/parcels" \
  -d "events[]=shipment.delivered" \
  -d "events[]=shipment.exception"

Events

EventSent when
shipment.createdA label is purchased
shipment.in_transitThe carrier scans the parcel for the first time
shipment.deliveredThe carrier confirms delivery
shipment.exceptionDelivery failed or the address was rejected
Verify every request. Compare the PW-Signature header with an HMAC-SHA256 of the raw body, using your endpoint secret. Reject anything older than five minutes.
